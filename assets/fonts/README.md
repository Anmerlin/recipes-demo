# Локальные шрифты

Для практики №3 подготовлено подключение Montserrat через `css/fonts.css`.

Поместите в эту папку файл:

```text
Montserrat-Regular.woff2
```

Он есть в архивах старого курса:

- `Example_buttons.zip`;
- `Example_img_background.zip`;
- `Example_modal_form.zip`.

В старых материалах доступен только Regular. Поэтому `font-weight: 600` и `700` на текущем этапе могут синтезироваться браузером. Когда будут доступны реальные Montserrat SemiBold и Bold, добавьте их отдельными `@font-face` в `css/fonts.css`.
