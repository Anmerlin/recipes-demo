# Recipes Demo

Учебный демо-проект курса веб-программирования. Проект будет развиваться поэтапно вместе с лекциями и практическими работами: от базовой HTML-структуры до полноценного интерфейса сервиса рецептов.

## Макет

В качестве основы используется макет **Recipes** в Figma:

https://www.figma.com/design/v12mxS9VWlE3znKPd6qP8V/Recipes-_-Cooking-Website-Homepage--Copy---Copy-?node-id=0-1&p=f&t=QCswLcSvGbImYLL1-0

На текущем этапе макет служит ориентиром для дальнейшей разработки. Полная верстка будет добавляться только по мере прохождения соответствующих тем курса.

## Текущий этап

Практическая работа №1 — подготовка проекта:

- создан репозиторий;
- работа ведется в отдельной ветке `lab/01-bootstrap`;
- подготовлен минимальный `index.html`;
- выполнен базовый анализ HTTP-запроса.

## Планируемые технологии

- HTML5;
- CSS3 — на следующих этапах курса;
- JavaScript — после прохождения соответствующих тем;
- Git и GitHub для контроля версий и работы через Pull Request.

## Запуск

На текущем этапе проект не использует сборщик и внешние зависимости.

1. Клонировать репозиторий.
2. Открыть файл `index.html` в браузере.

## Работа с ветками

Основная ветка проекта — `main`. Каждая практическая работа выполняется в отдельной ветке и после проверки объединяется с `main` через Pull Request.

## Использование AI

AI использовался как вспомогательный инструмент для структурирования README, проверки минимальной HTML-структуры и подготовки описания HTTP-запроса. Полученные предложения сопоставлялись с требованиями практической работы; реализация не включает темы, которые еще не были пройдены в курсе.
