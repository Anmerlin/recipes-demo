# Recipes Demo

Учебный демо-проект курса веб-программирования. Проект развивается поэтапно вместе с лекциями и практическими работами: от базовой HTML-структуры до полноценного интерфейса сервиса рецептов.

## Макет

В качестве основы используется макет **Recipes** в Figma:

https://www.figma.com/design/v12mxS9VWlE3znKPd6qP8V/Recipes-_-Cooking-Website-Homepage--Copy---Copy-?node-id=0-1&p=f&t=QCswLcSvGbImYLL1-0

## Текущий этап

Практическая работа №2 — первая верстка по макету.

На этом этапе реализованы:

- шапка сайта с логотипом, навигацией и ссылкой входа;
- hero-блок главной страницы;
- кнопки основных действий;
- секция «Умная сортировка по тегам»;
- четыре карточки категорий;
- базовая раскладка с помощью Flexbox;
- основные размеры, отступы, цвета, скругления и тени из макета.

Фотография hero-блока и оригинальные иконки пока не добавлены в репозиторий: ссылки на ассеты, получаемые из Figma, временные. На текущем учебном этапе они заменены стабильными заглушками и будут добавлены отдельно, когда в проекте появится постоянная структура для графики.

## Планируемые технологии

- HTML5;
- CSS3;
- JavaScript — после прохождения соответствующих тем;
- Git и GitHub для контроля версий и работы через Pull Request.

## Запуск

Проект не использует сборщик и внешние зависимости.

1. Клонировать репозиторий.
2. Открыть файл `index.html` в браузере.

## Работа с ветками

Основная ветка проекта — `main`. Каждая практическая работа выполняется в отдельной ветке и после проверки объединяется с `main` через Pull Request.

Текущая ветка практической работы: `lab/02-layout`.

## Использование AI

AI использовался как вспомогательный инструмент для анализа структуры Figma-макета, сопоставления размеров и отступов, а также для проверки HTML- и CSS-структуры. Сгенерированный Figma-контекст не копировался напрямую: React/Tailwind-представление было адаптировано к учебному проекту на чистых HTML и CSS без добавления новых библиотек.
