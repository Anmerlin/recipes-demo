# Recipes Demo

Учебный демо-проект курса веб-программирования. Проект развивается поэтапно вместе с лекциями и практическими работами: от базовой HTML-структуры до полноценного интерфейса сервиса рецептов.

## Макет

В качестве основы используется макет **Recipes** в Figma:

https://www.figma.com/design/v12mxS9VWlE3znKPd6qP8V/Recipes-_-Cooking-Website-Homepage--Copy---Copy-?node-id=0-1&p=f&t=QCswLcSvGbImYLL1-0

Макет используется как источник структуры, контента и графики. Визуальная реализация добавляется только по мере прохождения соответствующих тем курса.

## Текущий этап

Завершена практическая работа №2 — **семантический HTML**.

На текущем этапе:

- подготовлен `docs/project-brief.md` с описанием продукта, пользователя и основного сценария;
- подготовлен `docs/semantic-map.md` с обоснованием выбора семантических HTML-элементов;
- главная страница размечена с использованием `header`, `nav`, `main`, `section`, `article`, `form` и `footer`;
- сохранён один основной `h1` и последовательная иерархия заголовков;
- добавлена поисковая форма с нативными HTML-элементами;
- добавлено содержательное изображение с осмысленным `alt`;
- выполнена проверка структуры на длинном контенте;
- CSS и JavaScript пока намеренно не используются.

Практические работы №1 и №2 приняты и объединены с `main` через Pull Request.

## Технологии

На текущем этапе используется:

- HTML5;
- Git и GitHub;
- GitHub Pull Requests;
- GitHub Pages.

На следующих этапах курса будут добавлены:

- CSS3;
- адаптивная вёрстка;
- JavaScript и дальнейшая функциональность — только после прохождения соответствующих тем.

## Запуск локально

Проект не использует сборщик и внешние зависимости.

1. Клонировать репозиторий.
2. Открыть файл `index.html` в браузере.

## Опубликованная версия

Актуальная версия ветки `main` публикуется через GitHub Pages:

https://anmerlin.github.io/recipes-demo/

После merge изменений в `main` GitHub Pages автоматически пересобирает опубликованную страницу.

## Работа с ветками

Основная ветка проекта — `main`. Каждая практическая работа выполняется в отдельной ветке и после проверки объединяется с `main` через Pull Request.

В репозитории не должно появляться решение темы раньше соответствующей лекции. Например, CSS и JavaScript не добавляются до тех пор, пока они не входят в текущий материал курса.

## Использование AI

AI используется как вспомогательный инструмент для анализа требований, сопоставления структуры страницы с Figma, обсуждения семантики HTML и проверки изменений в Pull Request. Полученные предложения сопоставляются с требованиями практической работы; AI не используется как причина добавлять темы, которые ещё не были пройдены в курсе.
